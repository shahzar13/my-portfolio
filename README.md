# My Portfolio

Personal portfolio website of **Shahzar Akram**, a student at the University of Lahore.

## Features
- Responsive Bootstrap 5 navbar, hero, about, education, skills, projects, contact and footer
- Skills shown with Bootstrap progress bars and badges
- Projects shown as Bootstrap cards with images and links
- Contact form with name, email and message fields
- Custom CSS animations on top of Bootstrap

## Built with
HTML5, Bootstrap 5 (CDN) and custom CSS

## Structure
```
index.html
style.css
images/
README.md
```

## Run locally
Open `index.html` in any browser.
